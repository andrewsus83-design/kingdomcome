# st-dominic

Letakkan file karakter di folder ini:

- `portrait.png`     → Gambar utama (512x512) untuk saint card & gallery
- `card.png`         → Card art (512x768) untuk collection view
- `avatar.png`       → Avatar kecil (128x128) untuk HUD & kingdom residents
- `full-body.png`    → Full body (512x1024) untuk saint detail screen

Format: PNG, transparent background disarankan untuk portrait/avatar
